# Smart PIR Motion Sensor Security Automation System

This project is a Smart PIR Motion Sensor Security Automation System developed using Arduino UNO and simulated using Wokwi. The system detects human motion using a PIR sensor and automatically controls an LED while displaying monitoring messages through the Serial Monitor.

## Components Used
- Arduino UNO
- PIR Motion Sensor
- LED
- Resistor

## Features
- Motion Detection using PIR Sensor
- Automation using IF/ELSE Logic
- Automatic LED Control
- Real-Time Monitoring using Serial Monitor

## Software Used
- Wokwi Simulator
- Arduino IDE

## Applications
- Home Security Systems
- Smart Automation Systems
- Motion Detection Systems
- Smart Surveillance Applications
